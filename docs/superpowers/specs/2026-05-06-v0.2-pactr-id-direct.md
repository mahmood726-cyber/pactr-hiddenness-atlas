## 1. Goal

Add a second discovery algorithm — PACTR-ID-direct EuropePMC search — and measure its sensitivity against the v0.1.0 pre-registered gold standard. The v0.1.0 NCT-bridge algorithm achieved sensitivity = 6.2% (1/30 algorithm vs 16/30 blinded human auditor). This spec tests whether searching EuropePMC directly by PACTR ID closes part of that gap.

**Primary estimand:** PACTR-ID-direct sensitivity = TP / (TP + FN), where positives are trials the blinded auditor classified as having a peer-reviewed publication (auditor_gate2 = True or auditor_gate1 = True; i.e., auditor_verdict contains at least one T).

## 3. What is New (v0.2)

A single new algorithm: **PACTR-ID-direct EuropePMC search**.

For each of the 30 pre-registered trials:
1. Extract the `trial_id` (a PACTR ID such as `PACTR201510001314191` or `PACTR2010030001971409`).
2. Query EuropePMC's REST API with the raw PACTR ID as the search term.
3. Parse the response; apply the match rule (see §4).
4. Record hit or no_hit per trial.
5. Aggregate into sensitivity / specificity / κ vs auditor gold standard.

---

## 4. EuropePMC Query Strategy

**Endpoint:**
```
https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=<PACTR_ID>&format=json&pageSize=25&resultType=core
```

**PACTR ID format variants.** PACTR IDs may appear with or without leading zeros, with or without the `PACTR` prefix, and in a small number of legacy formats (e.g. `PACTR2010030001971409` has 20 characters vs the modern 19-character form). The query uses the raw ID as stored in the registry. The match rule (below) is case-insensitive to handle any case variation in papers.

**PACTR ID regex for match detection:**
```python
import re
PACTR_RE = re.compile(r'PACTR\d{10,}', re.IGNORECASE)
```
This matches any string beginning with `PACTR` (case-insensitive) followed by 10 or more digits — covers all known PACTR ID lengths.

**Match rule:** A trial is classified as a `hit` if ALL of the following hold:
1. The API response contains at least one article in `resultList.result`.
2. At least one returned article has a non-empty `pmid` field.
3. At least one returned article contains the queried PACTR ID in its `title` OR `abstractText` field (case-insensitive substring match).

Rationale for condition 3: EuropePMC free-text search on a PACTR ID may return false positives (e.g. a systematic review mentioning many trial IDs). Requiring the PACTR ID to appear in title or abstract filters to papers that actively cite the trial. This is the same "generous" threshold used by the v0.1.0 blinded auditor (auditor_gate2: any paper mentioning the PACTR ID or describing the trial).

**Upper-bound interpretation (Risk R3):** A paper that cites many PACTR IDs (e.g. a systematic review) could be counted as a hit for multiple trials. For v0.2, any such hit is counted — the sensitivity estimate is therefore an upper bound. v0.3 will add a primary-publication filter.

| PACTR-ID-direct (v0.2) | TBD | TBD | 16 (same gold standard) |
| Blinded auditor | 16 | n/a (gold std) | — |

The 2×2 table:
- **TP:** auditor positive AND PACTR-direct hit
- **FN:** auditor positive AND PACTR-direct no_hit
- **FP:** auditor negative AND PACTR-direct hit (false positive — algorithm over-includes)
- **TN:** auditor negative AND PACTR-direct no_hit

Sensitivity = TP / (TP + FN); Wilson 95% CI.  
Specificity = TN / (TN + FP); Wilson 95% CI.  
Cohen's κ between auditor binary verdict and PACTR-direct binary classification.

## 8. Risks

**R1 — EuropePMC rate limits.**  
Mitigation: throttle to ≤3 requests/second (`time.sleep(0.34)` between calls). Use exponential-backoff retry (max 3 attempts). Cache per-PACTR-ID response in `data/v0.2/.cache/<PACTR_ID>.json`. If EuropePMC is unreachable after 3 retries, abort with a non-zero exit code and report — do NOT fabricate results.

**R2 — PACTR ID format variants.**  
PACTR IDs appear in forms like `PACTR201404000817349` (19 chars) or `PACTR2010030001971409` (22 chars, legacy). The API query uses the raw ID exactly as stored. The title/abstract match uses `PACTR_RE = re.compile(r'PACTR\d{10,}', re.IGNORECASE)` to handle any variant. Match is case-insensitive. The queried PACTR ID must appear verbatim (as a substring) in the article text after lowercasing both.

**R3 — False positives.**  
A systematic review citing many trials may trigger a hit for one specific trial. For v0.2, any hit is counted — the sensitivity estimate should be interpreted as an upper bound on true primary-publication discovery. The specificity metric (TN / (TN + FP)) captures this: a low specificity signals over-inclusion. v0.3 will add a primary-publication filter (same first/last author or enrollment year ±2).

**R4 — Sample size.**  
n=30 with 16 auditor positives. Wilson 95% CI for sensitivity is wide at any value (e.g., 53% ±18%). This is carried forward from v0.1.0; the pre-registered n=30 is fixed.
